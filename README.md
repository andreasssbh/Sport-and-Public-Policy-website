# Sport-and-Public-Policy-website
Victors new website that is made to create a space for clear, concise, and accessible analysis of sport and public policy, using concrete examples to explain key issues, debates, and their implications.

- `index.html` — the whole site (bilingual ES/EN blog, no build step).
- Editing: Víctor logs in with a password at `/#acceso` and edits the site in place; every save is a commit here.
  Setup and usage: [`docs/EDITOR.md`](docs/EDITOR.md).
